# Battle Royale — Offline FPS

GitHub Pages用の完全オフラインFPSプロトタイプです。フォルダ名は「バトルロイヤル」の英語表記から `battle-royale` にしています。

## 配置
`EfaYukacoonar.github.io/games/battle-royale/` に、このフォルダの中身をそのまま配置してください。

## 特徴
- プレイヤー + 99 Bot = 100人規模
- Bot難易度 0〜100
- 高低差のあるプロシージャル地形
- 20種類のオリジナル武器
- ADS / リロード / 弾薬 / スプリント / ジャンプ
- セーフゾーン縮小
- 完全ローカル動作。CDN・API・ログイン・サーバー通信なし
- PC向けキーボード + マウス操作

## 注意
これは「完成版AAAゲーム」ではなく、GitHub Pagesで動く土台となるブラウザFPSです。Three.js等の外部ライブラリを使わず、WebGLを直接使っています。そのためオフライン性を優先しています。
